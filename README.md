# Klyvolt - Banco de Dados

Sistema de gestão energética para monitoramento de consumo de máquinas.

## Estrutura do Banco

- **8 tabelas**: empresa, usuario, setor, localizacao, maquina, tarifa_energia, leitura, consumo
- **PostgreSQL** + **Supabase**
- **Schema reproduzível** a partir do arquivo database/schema.sql

## Como executar

1. Criar banco no Supabase/PostgreSQL
2. Executar o arquivo `database/schema.sql`
3. Executar `database/testes_crud.sql` para testar
4. Executar `database/testes_integridade.sql` para validar
